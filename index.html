Recompiler l'application macOS (.app & .dmg)

🍎 macOS uniquement

Recompile instantanément le binaire natif macOS Apple Silicon / Intel et génère l'image disque .dmg prête à l'emploi avec tous vos derniers écrits.

💻 Compatibilité : Cette recompilation s'exécute directement sur ce Mac (100% hors-ligne, ~2s). Elle ne fonctionne que sur un système macOS.

Générer le compilateur Windows (.exe hors-ligne)

🪟 Windows uniquement

Prépare le pack autonome contenant build_windows_app.bat, le lanceur hors-ligne et l'intégralité de vos textes récents dans seed_writings.json.

💻 Compatibilité : La compilation d'un .exe natif ne fonctionne que sur un ordinateur Windows (Windows 10/11). Ce bouton télécharge le kit complet : lancez build_windows_app.bat sur votre PC Windows pour produire le .exe 100% hors-ligne.

Générer le compilateur Linux (.AppImage hors-ligne)

🐧 Linux uniquement

Prépare le pack autonome contenant build_linux_app.sh, l'exécutable autonome et l'intégralité des textes dans seed_writings.json.

💻 Compatibilité : La compilation d'un .AppImage universel ne fonctionne que sur un ordinateur Linux (Ubuntu, Debian, Fedora, Arch). Ce bouton télécharge le kit complet : lancez ./build_linux_app.sh sur votre PC Linux pour produire l'AppImage 100% hors-ligne.
